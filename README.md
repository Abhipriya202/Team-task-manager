# Team Task Manager 

This is a simple backend project built to manage team tasks, projects, and user roles. It helps teams organize work, assign tasks, and track progress in an easy way.

---

## What this project does

- Users can register and login
- JWT-based authentication is used for security
- Admin can create projects and assign tasks
- Members can view and update their tasks
- Dashboard shows task statistics like pending, completed, and overdue tasks

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT Authentication
